# Agent instructions

Maintain reusable agent skills, supporting templates, samples, and verification guidance within the user's assignment. Read [repository boundaries](README.md#repository-boundaries) before adding resources.

Follow the consuming repository's instructions when applying a skill. Consult Governance's authoritative rules and artifact contracts for governed work. Do not duplicate or weaken those rules, claim role authority, fabricate approval evidence, or treat examples as operational records.

Keep production framework mechanisms and their executable tests in vc.Ifx. Keep application-specific requirements, designs, implementation, and evidence in the consuming application. Changes to sibling repositories require an assignment covering them.

Preserve the user-requested ILoggerFactory constructor in initialization templates. Check the actual ComponentBase API before adapting a sample. Do not change Ifx to make a sample fit. Keep types in separate files and use unprefixed fields.

Use the [skill verification guide](verification/README.md) when maintaining skills. Validate Markdown links and metadata, and run the skill-creator quick validator when available. Report whether code was compiled; source inspection alone is not compilation.
