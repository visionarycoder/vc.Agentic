# Repository agent instruction maintenance

Use for maintaining instruction assets and discovery links. Changes to Method rules, decision rights, lifecycle gates, or formal artifact contracts belong to Governance and its specialized documentation skills.

## Establish the placement contract

Read the user request, root AGENTS.md, applicable nested instructions, catalogs, and the intended client's discovery rules. Identify canonical instructions and adapters before moving files.

The source variants disagree between `.github`, `.agents`, `.sandbox`, and `docs/instructions`. These are historical repository conventions, not universal placement requirements. A root AGENTS.md is not invalid merely because an old variant rejects loose root files. Do not move all documentation to a sandbox or invent unsupported discovery paths.

## Workflow

1. Inventory instructions, prompts, role profiles, skills, discovery pointers, support files, and references. Distinguish active instructions from archived data.
2. Classify by full intent, owning repository, client context, source authority, and dependencies. Respect assigned shared and repository-specific ownership.
3. Compare substantive instructions and support assets. Merge equivalents, retain meaningful context, and expose contradictions. Do not choose a winner solely by timestamp, length, or name.
4. Name the task and its product/domain context. Record old names as catalog aliases with one destination rather than creating duplicate discoverable wrappers.
5. Apply authorized moves and merges, preserving provenance, attribution, and required adapters. A pointer is useful only if the client follows it; describe discovery limits.
6. Update catalogs, inventories, references, examples, and tests. Preserve approval history and distinguish editorial maintenance from substantive policy changes.
7. Validate metadata, navigation, formatting, and required repository checks. Verify actual discovery only when that client is available. File placement alone does not establish installation or enforcement.

Report canonical names, destinations, mappings, checks, and unresolved context. Do not delete an authorized archive or weaken governing rules merely to pass a placement check.
