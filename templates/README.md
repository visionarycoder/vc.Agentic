# Supporting template catalog

| Template | Use |
| --- | --- |
| [Task brief](task-brief.md) | Describe an assigned task and its evidence expectations |

These supporting templates yield to the consuming project's authoritative artifact contracts. Governance owns formal requirements, design, approval, and acceptance templates. Filled examples do not grant authority.
